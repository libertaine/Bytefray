# Historical Core Seeker fixture

`core_seeker` is the frozen Agent API v1 characterization subject used by
the archived v2 alpha.6/alpha.7 timing studies. Its `agent.py` and
`agent.yaml` remain byte-identical historical data; it is not registered,
discoverable, or executable by current Bytefray.

Bytefray v5.0.0 is the last release that can execute this package.
