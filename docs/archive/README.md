# Bytefray Historical Documentation Archive

This directory contains historical Bytefray research, qualification, and design
records from completed release generations (v1 through v4).

These files are preserved for engineering provenance, experimental reproducibility,
and architectural reference. They describe the evolutionary development of the
engine across previous release milestones and do not necessarily describe current
supported behavior.

- **Current product documentation:** [`docs/`](../)
- **Current V5 research and development records:**
  [`docs/research/v5/`](../research/v5/)
- **Supported V4 contracts:** [`RULES_V4.md`](../RULES_V4.md),
  [`V4_ALPHA1_DESIGN.md`](../V4_ALPHA1_DESIGN.md), and
  [`V4_ALPHA2_DESIGN.md`](../V4_ALPHA2_DESIGN.md)
- **Completed V4 engineering history:** [`archive/v4/`](v4/) and the retained
  supporting record under [`docs/research/v4/`](../research/v4/)
- **Historical release records:** [`docs/releases/`](../releases/)

## Archive Directory Layout

- `v1/`: Bytefray v0.x and v1.x architecture, scaling benchmarks, ruleset extraction, and evaluation infrastructure records.
- `v2/`: Bytefray v2.x multi-entrant arena research, reactive defense, spatial characterization, and beta qualification reports.
- `v3/`: Bytefray v3.0 research baseline, bounded-locality feasibility (falsified), payoff economics, defensive event design/qualification, and RC1 defect resolution.
- `v4/`: Completed V4 gameplay-study, Alpha2 qualification, and documentation-reorganization records.
