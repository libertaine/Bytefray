## 3. Behavior and acceptance evidence

Keeper declares one `main` process, reach128/share1.0. Reset clears its counter,
read cursor, preceding action and delivered sample history. It never MOVEs.
Its own entrant ID and arena/sensing availability come from the reset context;
decisions otherwise use ObservationV2, declared parameters and stored own state.
Source audit found no seed/RNG use, placement import, host file/time access,
opponent callback access, or trace/replay/fixture consumption.

Each callback consumes the preceding own action once. An applied own-core READ
with a delivered value and non-own owner, including unowned, causes one legal
same-cell `0x4b` WRITE. Otherwise an applied positive SENSE receipt causes one
WRITE to its smallest currently reachable coordinate. Empty samples are retained;
missing/refused feedback supplies no target or repair evidence. Only then may a
due legal own-core-relative scan occur; otherwise the next of eight modular core
cells is READ. READ issuance advances the cursor. Suppression advances no policy
counter. Subsequent WRITE feedback is never interpreted as a hit or repair proof.
